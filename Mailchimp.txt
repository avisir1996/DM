MAILCHIMP EMBEDDED FORM IN WORDPRESS USING ELEMENTOR

STEP 1: LOGIN TO MAILCHIMP
1. Open https://mailchimp.com/
2. Click Login and open your account.

STEP 2: CREATE EMBEDDED FORM
1. Go to Forms → Create Forms → Embedded Forms.
2. Enter Form Name: Website Contact Signup.
3. Select fields: Name, Phone, Email.
4. Click Publish and copy the HTML code.

STEP 3: OPEN WORDPRESS
1. Pages → Contact → Edit with Elementor.
2. Search for the HTML Widget.
3. Drag and drop it onto the page.

STEP 4: PASTE HTML CODE
1. Paste the copied Mailchimp HTML code into the HTML Widget.
2. Publish

STEP 5: TEST FORM
1. Open the Contact page.
2. Fill in Name, Phone and Email.
3. Submit.

STEP 6: CHECK CONTACTS
1. Open Mailchimp.
2. Go to Audience → All Contacts.
3. Check the submitted contact details.
